# QuLattice-Decoy: A 4-Layer Post-Quantum Hybrid Cryptosystem

## 🚀 Project Overview
**QuLattice-Decoy** is an advanced post-quantum hybrid cryptographic framework designed to secure communications against quantum computing threats. It integrates Learning With Errors (LWE) primitives with a 4-layer hardware-software security pipeline and a 10-channel decoy routing logic.
